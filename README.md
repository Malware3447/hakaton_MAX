# Накладная в кармане

Бот в MAX, который ведёт электронную транспортную накладную (ЭТрН) одной перевозки от отгрузки
в учётной системе до подписанного четвёртого титула и доводит каждый шаг до конкретного человека
в его личной переписке с ботом: диспетчера отправителя, перевозчика, водителя и получателя без своего ЭДО.

Хакатон MAX 2026, трек «Эффективный бизнес», команда 397.

> Статус: каркас (HAKATON-8). Разделы ниже заполняются по мере разработки; к сдаче 30.09.2026 заполнены все.

## Быстрый старт

```bash
cp .env.example .env   # можно не заполнять: по умолчанию MAX_MODE=off
docker compose up --build
curl http://localhost:3000/healthz
```

## 3. Состав и архитектура решения

| Часть | Где | Что делает |
|---|---|---|
| `apps/app` | контейнер `app` | вебхук MAX, бот, ядро перевозки, адаптеры, очереди и таймеры (pg-boss) |
| `packages/domain` | библиотека | контракты, машина состояний, правила «чей ход» — без базы и сети |
| `packages/etrn` | библиотека | XML титулов Т1–Т4 по формату ФНС 5.01, проверка по XSD, PDF, openssl |
| PostgreSQL 18 | контейнер `postgres` | перевозки, участники, титулы, подписи, журнал; схема `mock` — модели внешних систем |

## 4. Запуск одной командой
`docker compose up --build` — поднимает базу и приложение. Сборка укладывается в 5 минут.

## 5. Параметры окружения, порты, зависимости
Переменные — в `.env.example` с комментариями. Порт приложения — `3000` (`APP_PORT` на хосте).
Зависимости с точными версиями — `package-lock.json`. Среда — Node.js 24 LTS.
