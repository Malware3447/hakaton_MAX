# Как работаем

- **Ветка на задачу**: `HAKATON-25-webhook-inbox`. В `main` — только через PR.
- **Короткие PR**: одна задача — один PR, чтобы его можно было прочитать за 10 минут.
- **Коммит начинается с ключа задачи**: `HAKATON-25: вебхук пишет обновления в inbox`.
- **Коммитят все участники** — жюри смотрит историю репозитория.
- **Только свой код и свободные зависимости** (MIT, Apache-2.0, BSD, ISC). Чужой и проприетарный код,
  закрытые библиотеки и код компаний участников нельзя (ограничение 7 Задания).
- **Секреты только в `.env`** на сервере. Токен бота не пишем в код, логи, задачи и чаты.
- **Задание трека не выкладываем**: папка `docs/zadanie/` в `.gitignore`, репозиторий публичный.
- **Контракты живые**: кто меняет схему базы, команды, состояния или интерфейсы адаптеров —
  правит их в коде и пишет одну строку в чат команды.
- Перед PR: `npm run check` (проверка типов и тесты).
- Всё смоделированное (оператор ЭПД, ГИС ЭПД, справочник, подпись организации) помечаем словом
  «модель» в интерфейсе и README.
